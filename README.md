# Daymix's Chess

Шахматы в браузере: полные правила, точные часы и игра по коду из пяти цифр — с любого устройства.

**Играть: <https://pro12447890.github.io/Daymix-s-Chess.Io-Game/>**

## Что внутри

- **Полные правила**: рокировка (с проверкой битых полей), взятие на проходе,
  превращение с выбором фигуры, шах и мат, пат, троекратное повторение позиции,
  правило 50 ходов, ничья при недостаточном материале.
- **Контроль времени**:
  - блиц — 30 секунд, 1 и 3 минуты;
  - рапид — 5, 10, 20 и 30 минут;
  - долгие — 45 и 60 минут;
  - без ограничений — 6 часов на игрока.
- **Два режима**:
  - *с другом здесь же* — одна доска на двоих, после каждого хода доска
    переворачивается (переключатель в панели справа);
  - *по сети* — нажмите «Создать код», получите пять цифр и передайте другу:
    он вводит код у себя и играет с другого устройства.
- **Оформление**: бежевые и тёмно-коричневые клетки, кружочки-подсказки с мягкой
  анимацией, плавное перемещение фигур, часы, список ходов в нотации SAN и
  сбитые фигуры.
- **Как на больших площадках**:
  - доска по центру экрана, координаты со всех четырёх сторон;
  - часы крупные, у игрока, который думает, они подсвечены;
  - список ходов с временем на каждый ход и названием дебюта;
  - просмотр партии кнопками ⏮ ‹ › ⏭ или стрелками клавиатуры;
  - вкладки «Ходы», «Чат» и «Информация»; в «Информации» — готовый PGN
    и кнопка «Скопировать PGN»;
  - чат сопернику в сетевой партии, индикатор связи у имён;
  - кнопка «Прервать» (до второго хода) рядом с «Ничья» и «Сдаться».
- **Переворот доски** — мгновенный, без промежуточной анимации.

## Как устроено

Три файла без сборки и зависимостей:

| Файл | Что делает |
|---|---|
| `index.html` | разметка экранов |
| `style.css` | коричневая тема и анимации |
| `app.js` | движок правил, сеть и интерфейс |

Движок проверен классическими тестами perft: начальная позиция (20 / 400 / 8902 /
197281), «Kiwipete» (48 / 2039 / 97862) и эндшпильная позиция (14 / 191 / 2812 /
43238).

Связь для игры по сети идёт через публичную службу [ntfy.sh](https://ntfy.sh):
подписка на канал комнаты — WebSocket, отправка хода — обычный POST. Код из пяти
цифр — это имя канала, поэтому для игры не нужны ни аккаунт, ни сервер.

## Локальный запуск

```sh
python -m http.server 8000
```

Откройте <http://localhost:8000>.
